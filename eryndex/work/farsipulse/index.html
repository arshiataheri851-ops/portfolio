FarsiPulse

A typed FastAPI service for binary Persian review-sentiment inference, with conservative Persian text normalization and reproducible model evaluation.

Implemented capabilities

  • Single-text and batch prediction endpoints, with batches capped at 32 items
  • Pydantic request validation and blank-input rejection
  • Persian Yeh/Kaf normalization while preserving meaningful ZWNJ characters
  • Lazy Hugging Face model loading with a pinned model revision
  • API-key validation for inference routes and a health endpoint
  • CPU-oriented Docker image and automated evaluation workflow

Architecture

HTTP client → FastAPI routes and Pydantic contracts → Persian text normalizer → lazy Hugging Face adapter → positive/negative scores and model provenance.

Evaluation and boundaries

The source repository documents a fixed in-domain SnappFood test-split evaluation. That benchmark is not a guarantee of performance on other Persian domains, dialects or live traffic. Scores are model outputs, not calibrated probabilities.

This is a portfolio demonstrator. Public deployment requires enforced API-key configuration, rate/concurrency limits, monitoring, privacy and retention controls, and an operational rollback process. No customer deployment or SLA is claimed.
