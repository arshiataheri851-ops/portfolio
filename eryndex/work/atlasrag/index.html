AtlasRAG

An authenticated multi-tenant document retrieval API with PostgreSQL full-text search, tenant-scoped document operations and source citations.

Implemented capabilities

  • Tenant-scoped document ingestion, batch ingestion, listing, deletion and retrieval
  • API-key authentication with fail-closed configuration
  • PostgreSQL 16 full-text search with a GIN index
  • Persian text normalization, including Yeh/Kaf and ZWNJ handling
  • Source-oriented citations and retrieval evaluation endpoints
  • Privacy-conscious audit events and protected Prometheus metrics

Architecture

FastAPI service → tenant API-key resolution → PostgreSQL document and chunk storage → lexical full-text retrieval → source references and extractive response.

Search boundaries

The current search engine is lexical PostgreSQL full-text search. It does not use vector embeddings and does not claim semantic or hybrid retrieval. The API provides extractive, source-oriented results; it does not claim LLM-generated answers.

Tenant isolation and authentication are implemented in the repository, but production readiness still depends on configured secrets, HTTPS, rate limits, monitoring, backup/restore drills and operational review. No customer deployment or SLA is claimed.
