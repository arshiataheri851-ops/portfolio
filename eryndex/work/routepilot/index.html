RoutePilot

Fleet and delivery operations MVP with a FastAPI and SQLite backend and browser dashboard.

What is implemented

  • Vehicle records and submitted GPS telemetry
  • Simulated vehicle positions and route paths
  • Delivery creation and status tracking
  • Proof-of-delivery metadata and delivery-note preview

Architecture

Browser dashboard → FastAPI → SQLite. Docker Compose starts the local API; health and readiness endpoints are provided.

Current boundaries

Not connected to live GPS hardware; no authentication, tenant isolation or real customer data protections. Sample data only.

Source & run instructions

Inspect the repository README and backend setup before running. This project is a demonstrator; do not treat it as a production service without the controls listed in its documentation.
