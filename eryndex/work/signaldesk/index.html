SignalDesk

Service desk MVP for creating, assigning, prioritizing and tracking support tickets.

What is implemented

  • Searchable request queue
  • Priority and SLA-risk filters
  • API-backed assignment and status changes
  • Per-ticket audit history
  • Transparent deterministic prioritization rules

Architecture

Browser dashboard → FastAPI → SQLite. Queue metrics and status changes are backed by the API when it is running.

Current boundaries

Not an AI triage system. Authentication, role permissions, tenant isolation, email intake and notifications are not implemented. Sample records are illustrative.

Source & run instructions

Inspect the repository README and backend setup before running. This project is a demonstrator; do not treat it as a production service without the controls listed in its documentation.
