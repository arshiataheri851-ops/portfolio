ENGINEERING NOTES

Reliability by design

Features include bounded retry attempts, delivery lifecycle metadata, and an injectable sender interface so tests do not make real network requests.

The default implementation uses a small in-memory store and has no outbound network sender configured. It is a reference implementation, not a durable production deployment.
