# Arshia Taheri — Portfolio

A responsive personal portfolio website published with GitHub Pages.

## Structure

- `index.html` — homepage
- `assets/style.css` — shared responsive styles
- `task-manager/` — Task Manager project page
- `instagram-downloader/` — Media Downloader project page

## GitHub Pages

In the repository, open **Settings → Pages** and select **Deploy from a branch**. Choose the `main` branch and the `/ (root)` folder, then save.

The expected site address is:

https://arshiataheri851-ops.github.io/portfolio/

Project pages:

- https://arshiataheri851-ops.github.io/portfolio/task-manager/
- https://arshiataheri851-ops.github.io/portfolio/instagram-downloader/

Replace the project descriptions and add source links only after verifying the details of each project.
